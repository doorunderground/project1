# Infinite Stair Game

**OpenCV / Python 기반 타이밍 액션 게임**  
무한히 생성되는 계단을 제한 시간 안에 정확한 방향으로 내려가는 반응형 게임

- 개발일: **2026.01.09**
- 개발자: **문지하, 김진수, 구효제**

---

## 프로젝트 개요

`Infinite Stair Game`은 플레이어의 **방향 판단 능력과 시간 압박 상황에서의 즉각적인 입력**을 핵심으로 한 타이밍 기반 액션 게임이다.

계단은 무한히 생성되며, 플레이어는 각 계단이 요구하는 방향에 맞게 이동하거나 특정 조건에서 **Gap(빈칸)**을 점프로 넘어가야 한다.

---

## 조작 방법

| 키 | 동작 |
|---|---|
| `A` | 왼쪽 이동 |
| `D` | 오른쪽 이동 |
| `SPACE` | Gap 계단 2칸 점프 |
| `R` | 게임 재시작 |
| `Q` | 게임 종료 |

---

## 핵심 게임 로직

### 1. 계단 생성 규칙
- 계단은 이전 계단 기준으로 **좌(-1) / 우(+1)** 중 하나로 랜덤 생성
- 화면 밖으로 벗어나는 방향은 자동 배제

### 2. Gap(빈칸) 계단
- 일정 확률로 `Gap` 계단 생성
- **연속 Gap 발생 방지**
  - Gap 다음 계단은 반드시 정상 계단
- Gap을 넘기 위해서는 `SPACE` 입력으로 **2칸 점프** 필요

### 3. 입력 판정
- 각 계단은 요구 방향(`dir`)을 가짐
- 플레이어 입력 방향이 일치해야 다음 계단으로 이동 가능
- 잘못된 입력 / 빈칸 착지 / 시간 초과 시 낙하 시작

---

## 난이도 설계 (Stage System)

- `STAGE_STEP`(기본 10칸)마다 스테이지 상승
- 스테이지가 올라갈수록:
  - 입력 제한 시간 감소
  - Gap 생성 확률 증가
  - 배경색 변화로 시각적 압박 증가

Stage 1 : 입력 제한 2.0초 / Gap 0%
Stage 2 : 입력 제한 1.85초 / Gap 10%
Stage 3 : 입력 제한 1.6초 / Gap 20%
...
최소 입력 제한 시간 : 0.6초


## 시간 압박 시스템 (Time Limit)

- 각 계단마다 **입력 제한 시간** 존재
- 제한 시간 안에 올바른 입력을 하지 못하면 즉시 **낙하(TIME OVER)** 상태로 전환
- 상단 **Time Bar(UI)** 를 통해 남은 입력 시간을 실시간으로 시각화

> 플레이어는 계단을 내려갈수록  
> 점점 줄어드는 제한 시간 속에서 빠른 판단과 입력을 요구받음

---

## 낙하 & Game Over 처리

### 낙하 조건
다음 중 하나라도 만족할 경우 캐릭터는 즉시 낙하 상태로 전환된다.

- 잘못된 방향 입력
- Gap(빈칸) 처리 실패
- 입력 제한 시간 초과

### Game Over 판정
- 낙하 후 캐릭터가 **화면 밖으로 완전히 벗어났을 때**
  → Game Over 확정

### Game Over 종류
| 종류 | 설명 |
|---|---|
| `GAME OVER` | 잘못된 입력 또는 Gap 처리 실패 |
| `TIME OVER` | 입력 제한 시간 초과 |

## 시각 효과 (Visual Effects)

### 계단 흔들림 효과 (Wobble Effect)
- **착지한 계단에만** 흔들림 적용
- 상·하 / 좌·우 방향 진동
- 시간이 지날수록 진폭이 줄어드는 **감쇠 애니메이션** 적용

### 배경 색상 변화
- 스테이지 진행에 따라 배경 색상 변경
- 난이도 상승을 **시각적으로 직관화**
- 플레이어에게 점진적인 압박감 제공
